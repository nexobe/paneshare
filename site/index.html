One window.
Two Macs.

paneshare opens a window from one Mac on another as a real Mac window. Click, type, scroll and resize it. No whole-screen share, no account, no server.

Features

It feels like the app is on your Mac.

paneshare streams one window, not your whole screen. On the other Mac it behaves like any other window.

A real window

It opens as a native Mac window with the source window's title. Move it, resize it, and the window on the other Mac resizes too.

Dock and Command-Tab

Each remote app gets its own Dock icon, named after the app and the Mac it runs on.

Sharp text

Windows are captured at the viewing Mac's pixel density and encoded in hardware, so text stays crisp on Retina screens.

App sound

Each shared app's sound comes along, with its own mute button and volume slider.

Home network or Tailscale

Macs on the same network find each other. On a tailnet, pair by address. There's no relay server in between.

Share links

Someone without paneshare can view one window in a browser on your network. Links expire, and you can revoke them.

Files and clipboard

Send files up to 2 GB and sync plain text. Both are off until you turn them on, on each Mac.

Headless Macs

A Mac mini with no screen can still share. An optional virtual display also fits windows bigger than the host's screen.

Keeps the host awake

While a window is open on another Mac, the host stays awake, then sleeps normally when you're done.

How it works

Pair once. Then just open windows.

Install paneshare on both Macs. Pairing takes a 6-digit code and about ten seconds.

Share on the host

Grant Screen Recording and Accessibility, turn sharing on, and tick the windows you want to offer.

Pair with a code

On the other Mac, click Pair. Type the code it shows into the prompt on the host.

482 913

Open a window

Click Open next to any shared window. It appears as a real window, with its own Dock icon.

Security

Your windows go to your Macs. Nowhere else.

There's no paneshare server and no account. Your Macs talk to each other directly, and only after you pair them.

Read the full security model →
  • End-to-end encryptedTLS 1.3 with certificates on both sides, pinned to each paired Mac's key.
  • Pairing you approveA one-time 6-digit code, checked with a PAKE so it can't be guessed offline.
  • Sensitive windows stay putPassword managers and system password prompts are never listed or captured.
  • Nothing listens when sharing is offThe port opens only while you share.
  • No telemetrypaneshare doesn't collect usage data. The source is open, so you can check.

FAQ

Questions

Is it free?

Yes. paneshare is free and open source under the MIT license, with six files under Apache-2.0.

Do I need an account?

No. There's no sign-up and no paneshare server. Your Macs pair with each other directly.

Does it work over the internet?

It works on the same network, or across the internet through a Tailscale tailnet. There's no relay server of ours in between.

How is this different from screen sharing?

Screen sharing shows a whole screen in one window. paneshare sends one window, and it opens as its own window with its own Dock icon, sized to fit the Mac you're on.

Which Macs does it run on?

macOS 14 Sonoma or later. Per-app sound uses a feature from macOS 14.2.

Why isn't it in the Mac App Store?

paneshare controls other apps' input and can use a private API for the virtual display. The App Store doesn't allow those, so paneshare ships as a signed, notarized download.

Who makes it?

NEXOBE INC. Releases are signed with Developer ID team TV289JZ58M and notarized by Apple.
