# Getting help

- **Questions and ideas:** start a thread in [Discussions](https://github.com/nexobe/paneshare/discussions).
- **Bugs:** open an [issue](https://github.com/nexobe/paneshare/issues/new/choose) with the bug report form.
  It asks for both Macs' details and the Problem report (This Mac tab > Copy Problem Report).
- **Security problems:** don't open a public issue. Report them privately: see [SECURITY.md](SECURITY.md).
- **Install problems:** check "Install" and "Known risks" in the [README](README.md) first. Most first-run
  problems are a missing Screen Recording, Accessibility or Local Network permission.

paneshare is maintained by a small team, so replies can take a few days.
