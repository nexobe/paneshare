# paneshare 0.1.1

- paneshare now tells you when macOS blocks Local Network access. Before, other Macs silently couldn't find
  this one. A banner, the setup screen and This Mac now show the problem and open the right settings pane.
- When you turn Local Network on and come back to paneshare, it looks for other Macs again.
- The problem report includes the Local Network state.

Requires macOS 14 or later.
