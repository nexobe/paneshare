# paneshare 0.1.0

The first public build.

- Share one window from a Mac and open it on another Mac as a native window, with its own Dock icon.
- Pair with a 6-digit code. Traffic is end-to-end encrypted with TLS 1.3 and pinned keys. No account, no server.
- App sound, share links for browser guests, file transfer, clipboard sync and a virtual display for headless Macs.

This is an early release. Streaming, input and pairing have run on two Macs. App sound, share links, files,
clipboard, Dock icons and the virtual display are built but not yet tested on two Macs. Please report problems on
GitHub.

Requires an Apple silicon Mac (M1 or later) and macOS 14 or later.
